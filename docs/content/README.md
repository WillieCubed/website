# Content

This page is for whoever adds or edits content files, Willie or an agent.
Start with the page for the content type you are changing, then run
`pnpm typecheck` and `pnpm test`.

- [Writings](./writings.md): articles and notes under `content/writings`, the
  frontmatter every post kind uses, how drafts and templates behave, and
  what the `syndicateTo` list a Micropub client writes means.
- [Feeds](./feeds.md): the RSS, Atom, and JSON routes, what each includes, and
  how to add a content type to them.
- [Initiatives](../initiatives.md): campaigns, series, and projects under
  `/initiatives`.
- [Projects](../projects.md): project categories and the `data/projects.json`
  shape.
- [IndieWeb](../indieweb/README.md): the protocol endpoints and microformats
  that content feeds into.
