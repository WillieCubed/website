# Publishing conformance

This matrix is for Willie and maintainers releasing willie.page. Resolve every applicable pending external check before calling a release fully interoperable. Record successful writes and subscriber receipt separately from HTTP acceptance and simulated behavior.

The baseline was inspected on October 7, 2026. The site is a publisher with response display. Microsub, a reader, a hosted PDS service, relays, and ActivityPub delivery are outside this contract. The acceptance runner can use temporary PDS infrastructure for verification. Existing authored drafts remain private.
