code to `willie.page`. Complete the open checks below before claiming the

Rapid Micropub commits exposed a workflow race. Runs
[35940667514](https://github.com/WillieCubed/website/actions/runs/35940667514),
[35940731470](https://github.com/WillieCubed/website/actions/runs/35940731470),
and [35940804817](https://github.com/WillieCubed/website/actions/runs/35940804817)
failed when a newer alias revision replaced the one they had polled; the last
run received HTTP 409 `revision_mismatch` from `/api/indieweb/notify`.
Commit `b1d7eda` cancels superseded jobs on the same branch. Later runs,
including [35941255659](https://github.com/WillieCubed/website/actions/runs/35941255659),
succeeded and scanned all published posts.

Micropub Rocks' older IndieAuth client did not send a PKCE verifier. The
[earlier record](verification-2026-09-23.md) separates that authorization
failure from the Micropub create cases. The current code keeps PKCE S256.
Authorship Rocks supplies sample authorship pages for consumers; it does not
validate an arbitrary publisher URL. Production publication, syndication,
and the IndieMark level claims remain pending the
[writing review](publication-review.md).
